# A股个股数据采集工具 - 产品需求文档

## 1. 项目概述

### 项目名称
**A股个股数据采集分析系统** (A-Stock Data Scraper & Analyzer)

### 核心价值
自动化采集A股个股关键数据，结合大模型进行智能分析，提供估值百分位、入场区间、风险评估等投资决策支持。

### 目标用户
- 个人投资者
- 量化交易研究者
- 金融数据分析师

---

## 2. 功能需求

### 2.1 数据采集模块
| 功能 | 描述 |
|------|------|
| 多源数据获取 | 支持同花顺、腾讯财经、通达信(mootdx)等平台 |
| 批量采集 | 支持股票代码列表批量抓取 |
| 关键词搜索 | 支持按行业、概念、名称关键词搜索 |
| 采集字段 | 股票代码、名称、流通市值、现价、所属行业、细分行业、所属概念(2-3个)、核心产品(2-3个) |

### 2.2 数据处理模块
| 功能 | 描述 |
|------|------|
| 数据清洗 | 去除空值、异常值、格式标准化 |
| 去重处理 | 按股票代码去重，保留最新数据 |
| 数据存储 | 支持CSV、Excel格式导出 |

### 2.3 智能分析模块
| 功能 | 描述 |
|------|------|
| 估值百分位 | 基于历史数据计算PE、PB百分位 |
| 入场区间 | 结合估值和趋势给出建议价格区间 |
| 止损位 | 根据波动率计算风险止损位 |
| 机会要点 | 分析核心投资逻辑 |
| 核心风险 | 识别主要风险因素 |

### 2.4 可视化模块
| 功能 | 描述 |
|------|------|
| 价格趋势图 | K线图、均线图展示 |
| 行业对比 | 行业推荐标注、横向对比 |
| 表格展示 | 支持排序、筛选、分页 |

### 2.5 交互接口
| 接口类型 | 描述 |
|----------|------|
| 命令行工具 | CLI工具，支持参数配置 |
| Web演示页面 | 实时数据展示、股票管理 |

### 3.2 技术栈
- **后端**: Python 3.8+, Flask, Pandas
- **爬虫**: Requests, BeautifulSoup4, mootdx
- **AI分析**: OpenAI API / Claude API (模拟)
- **可视化**: Plotly, Chart.js
- **前端**: React, Ant Design
- **数据存储**: SQLite, CSV

## 5. 验收标准

### 5.1 功能验收
- [ ] 支持从至少2个数据源获取数据
- [ ] 批量采集成功率 > 95%
- [ ] 数据清洗后无空值、格式统一
- [ ] CLI工具完整可用
- [ ] Web页面支持股票增删改查
- [ ] 实时数据更新功能正常

### 5.2 性能验收
- [ ] 单股票采集响应时间 < 3秒
- [ ] 批量采集(100只) < 5分钟
- [ ] Web页面加载时间 < 2秒

### 5.3 可视化验收
- [ ] 价格趋势图表正常显示
- [ ] 支持按行业/细分行业排序
- [ ] 表格支持分页和筛选

---

## 6. 非功能性需求

### 6.1 可靠性
- 采集失败自动重试(最多3次)
- 异常数据记录日志
- 数据完整性校验

### 6.2 安全性
- 不存储用户敏感信息
- API调用限流保护
- 合规使用数据源

### 6.3 可维护性
- 模块化设计，便于扩展
- 完整日志记录
- 单元测试覆盖核心模块
